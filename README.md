# ⚡ Mi Racha

¡Bienvenido al repositorio de **Mi Racha**! 

**Mi Racha** es una aplicación web diseñada para llevar el control del tiempo dedicado al estudio o trabajo diario. Cuenta con un sistema de **"Racha"** (*streaks*) que contabiliza cuántos días consecutivos has registrado tus actividades, ayudándote a mantener la constancia y el hábito.

---

## 🚀 Inicio Rápido

* Para usuarios desde computadora:

1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en tu navegador web preferido.

* Para usuarios desde teléfono o tablet:

1. Abrir desde el siguiente enlace: https://kc-programer.github.io/Mi-Racha/
(**Nota:** Se necesita conexión a internet al abrirlo por primera vez, a partir de ahí la app se puede usar con o sin conexión.)

#### Advertencia⚠️: 
En el móvil **no** sirve descargar el ZIP y abrir `index.html`: Android lo abre aislado, sin `estilos.css` ni `app.js` al lado, así que la página sale sin estilos y sin funcionar. En el teléfono, siempre la URL indicada.

---

## 🛠️ Detalles Técnicos

* **Lenguajes:** HTML5, CSS3 y JavaScript (JS).
* **Asistencia en Desarrollo:** Desarrollado con el soporte de la herramienta de IA **Opencode**.
* **Gestión y Control:** Utiliza **JSON** y archivos **`.md`** (Markdown) para el control del proceso de desarrollo y la creación de utilidades que agilizan el flujo de trabajo.
