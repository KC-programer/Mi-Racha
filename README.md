# Fichero "README" que debe leerse antes de todo!!

Bienvenido. El repositorio en el que estas es el de la aplicación web "Mi Racha".

La aplicación web "Mi Racha" es una aplicación hecha para llevar un control de lo que se ha estudiado y/o trabajado durante el día. Además, la app web incluye un sistema de "Racha", que funciona para llevar una cuenta de cuantos días seguidos se ha hecho un reporte de lo hecho en el día.
Para empezar a usarla basta con abrir el archivo "index.html".

### En detalles más técnicos...

-> La app se desarrollo usando los lenguajes HTML, CSS y JS.

-> Se desarrolló usando la herramienta de IA "Opencode".

-> Ocupa las tecnologías "JSON" y archivos ".md" para la creación de archivos Markdown que sirvan como control del proceso y creación de herramientas que ayuden a un desarrollo más rápido.
